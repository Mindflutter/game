# Abyss

A 2D action roguelite, in the browser as a throwaway prototype of a native
game. This file only points; the rules live in `docs/` (D131 (CLAUDE.md is an
index)).

## Every session, before the first reply

1. `docs/foundations.md` — what does not change before alpha: the glossary,
   the genre contract, the pillars, the technical contract, the non-goals.
2. `docs/plan.md` — the stages, and which one is active.
3. `docs/working.md` — how Igor and Claude work: the reply, questions, commits,
   and the consistency sweep that ends every change.

## Only when the session needs it

| When | Read |
|---|---|
| Writing, changing or checking code | `docs/code.md` |
| Adding or changing a piece of content | the `abyss-content` skill |
| A change needs Igor's play, or a play-test was played | the `sonar` skill |
| Running the game, the suites, a scenario, the debug mode | `README.md` |
| Anything else | `docs/README.md`, the map of every doc |
