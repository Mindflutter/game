**Goal:** One layer scrolls: a current carries the camera between gate depths, stops at each batch, and ends on a "THE BOTTOM" stop screen.

**Architecture:** `game/` gains a world-space camera (`cameraY`) and a descent (`descend()`), driven from the existing gate block in `step()`. `aim` stays in view coordinates on the platform side; `game/` adds `cameraY` where it reads it, so the port seam stays at six names. `platform/render.js` translates world draws by `-cameraY` and adds world-fixed specks plus a depth tint.

**Tech Stack:** plain browser JS (no modules, no dependencies), Canvas 2D; Vitest + fast-check in Node for logic; `index.html?test` for the browser-only D29 check.

**Spec:** `docs/superpowers/specs/2026-09-28-s2-descent-design.md`

## Global Constraints

- No runtime dependencies, no asset files, plain `<script>` tags (CLAUDE.md → Hard constraints).

// than popping into view. The view, not the world: the world is a tall strip.
function edgeSpawnPoint() {
  const m = 40;
  const edge = Math.floor(rng() * 4);    // 0 top, 1 right, 2 bottom, 3 left
  if (edge === 0) return { x: rng() * ARENA_W, y: cameraY - m };

  if (edge === 2) return { x: rng() * ARENA_W, y: cameraY + ARENA_H + m };

- [ ] **Step 7: Add `descend()`** — `game/logic.js`, a new section directly before `// ---------- update ----------`:

```js
// ---------- the descent ----------
// Between gates the water moves (S2). The current eases in, cruises, and
// brakes to a stop exactly at the next gate depth -- the camera cannot arrive
// early, late, or past it, because a batch has to find you *at* its depth.
// Swimming below SWIM_LINE pulls the camera after you, which is how the player
// speeds a descent up: no new key, it is just S.
function descend(dt, target) {
  descentTime += dt;
  // The fastest speed that can still stop at `target`, braking at the rate the
  // current eased in: v^2 = 2as. Near the end one step overshoots in theory,
  // and the Math.min below lands it on `target` exactly.
  const brake = Math.sqrt(2 * (CURRENT_SPEED / CURRENT_EASE) * (target - cameraY));
  const current = Math.min(CURRENT_SPEED * Math.min(1, descentTime / CURRENT_EASE), brake);
  // The speed that would put a player below the line back on it this tick.
  const follow = (player.y - cameraY - SWIM_LINE * ARENA_H) / dt;
  cameraY = Math.min(target, cameraY + Math.min(brake, Math.max(current, follow)) * dt);
  // The current carries the player as well as the view. Without this the view
  // would outrun them and the top edge would drag them down like a wall.
  player.y += current * dt;
}
```

// Takes a size so the D29 check can play the same dive at three window sizes;
// the listener wraps it, or the resize *event* would arrive as `w`.
function resize(w = window.innerWidth, h = window.innerHeight) {
  canvas.width = w;
  canvas.height = h;
  scale = Math.min(canvas.width / ARENA_W, canvas.height / ARENA_H);
  offX = (canvas.width  - ARENA_W * scale) / 2;
  offY = (canvas.height - ARENA_H * scale) / 2;
}
window.addEventListener('resize', () => resize());
